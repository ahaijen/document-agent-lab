Oracle AI Agent Studio · Hands-on lab

Build a document agent

Create an Expense Policy Agent that answers employee questions from an uploaded policy document.

Estimated time: 30–45 minutesLevel: Intermediate
Start the lab ↓

What you will build

Policy Q&A, grounded in a document

By the end of this lab, users can ask a question such as “Can I fly business class?” and receive an answer based on the policy PDF you uploaded.

Before you begin

  • Access to Oracle AI Agent Studio in your Fusion environment.
  • A PDF version of the policy you want the agent to answer questions about.
  • Permission to create and publish document tools, agents, and workflows.

Use your own names and codes if your environment requires uniqueness. The values below are examples from this lab.

Step 1

Create the document tool

In AI Agent Studio, create a new Document tool. Use the assistant prompt below to populate the required values, then review the generated fields before you create it.

Prompt for AI Agent Studio
Fill in the required fields for a document tool that will contain our company expense policy. Set the family to Common and the product to Other. Create a document entry named "Company Expense Policy". I will upload the policy PDF after the tool is created.
Example tool nameExpense Policy Document Tool
Example tool codeEXPENSE_POLICY_DOCUMENT_TOOL
Document entryCompany Expense Policy

Upload the policy PDF to the document entry. Wait until the document has finished processing and is ready to publish, then save the tool.

Step 2

Create a reusable policy agent

Create a new agent, add the document tool from Step 1, and configure it as a reusable agent. The agent should answer policy questions only from the uploaded document.

Agent role and prompt
You answer employee questions about the company expense policy. Use the Expense Policy Document Tool as the source of truth. Give concise, helpful answers grounded in the document. If the document does not contain the answer, say so clearly and suggest the user contact the appropriate policy owner. Do not invent policy details.
Example agent nameExpense Policy Agent
Example agent codeEXPENSE_POLICY_AGENT
Agent typeReusable

Attach your document tool to the agent. Review the model settings that apply in your environment, then save the agent.

Step 3

Connect the agent in a workflow

Create a workflow that accepts a user’s question and routes it to the reusable policy agent. A simple Start → Agent flow is enough for this lab.

Workflow prompt
Create a workflow that uses a single Agent node configured with the reusable agent code "EXPENSE_POLICY_AGENT". The workflow must accept a user's question as input and return the agent's answer. Connect the Start node directly to the Agent node and configure the agent node to handle the user's question.

If you use a different agent code, replace it in the prompt before you submit it. Confirm the proposed change, then review the node settings and save the workflow.

Step 4

Test, validate, and publish

  1. Ask a question covered by your uploaded policy.
  2. Check that the answer matches the policy and does not add unsupported details.
  3. Publish the tool, agent, and workflow according to your team’s release process.
Suggested test question
Can I fly business class?

Expected behavior: the answer must reflect your uploaded policy. In the lab example, business class depends on flight duration and required approvals.

You’re done

Take it further

Try a second policy document, add a handoff path for questions the policy does not answer, or create a focused workflow for a different employee policy.

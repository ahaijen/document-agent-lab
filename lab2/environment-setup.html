Facilitator pre-work

Import the Supplier Query Team

This imports the Business Object and tool required by the Supplier Inquiry Workflow lab.

  1. Download the Supplier Query Team configuration.
  2. Navigate to Marketplace > Supervisor Agent.
  3. Click Import and upload the downloaded JSON file.
  4. After the import finishes, participants can start the lab.
